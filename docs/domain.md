# Domain handbook

- [Projects tool](domain/projects-tool.md) — Register, create, list, and remove projects bound to one machine.
- [Machines tool](domain/machines-tool.md) — Discover machines, check prerequisites, and choose the default for independent research.
- [Task tool](domain/task-tool.md) — Start project work on its registered machine or independent research on a chosen machine.
- [Workers tool](domain/workers-tool.md) — Read, steer, interrupt, relaunch, land, close, and recover workers without moving them.
- [Reports tool](domain/reports-tool.md) — Find and read collected scout reports in the controller-local archive, including offline.
- [Usage tool](domain/usage-tool.md) — See remaining usage for one host's worker accounts and configuration.
- [Models tool](domain/models-tool.md) — Query one host's catalog and remember controller-local preferences.

For manual host setup and prerequisite remedies, read [Remote helper provisioning](remote-helper.md). For supported versus actually tested platforms, read [README.md](../README.md#requirements-and-verification-status).
